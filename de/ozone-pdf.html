Ozone PDF

Ihre PDFs, ohne sie ins Internet hochzuladen.

Dokumente kostenlos zusammenführen, teilen, komprimieren, schützen und scannen. Alles passiert auf Ihrem Computer.

Kostenlos herunterladen So funktioniert es

Für Windows 10 und 11. Kostenlos und quelloffen.

Warum ich es gemacht habe

Ich habe es gebaut, weil ich gesehen habe, wie viele Menschen, die mit sensiblen Informationen arbeiten, in den unterschiedlichsten Branchen Websites nutzen, um ein PDF zusammenzuführen oder zu verkleinern: Verträge, Gehaltsabrechnungen und Ausweise landeten auf Seiten, von denen niemand weiß, wer sie betreibt. Heute, mit immer häufigeren Cyberangriffen und künstlicher Intelligenz, die sie erleichtert, ist ein ins Internet hochgeladenes Dokument ein offengelegtes Dokument. Ozone PDF macht dasselbe wie diese Seiten, aber alles passiert auf Ihrem Computer.

Mehrere PDFs zu einer zusammenfügen

Ziehen Sie die Dateien ins Fenster, ordnen Sie sie beliebig an – fertig: Es entsteht eine einzige PDF. Ihr Original bleibt unverändert, es wird immer eine neue Kopie gespeichert.

Teilen, damit es in die E-Mail passt

Das System nimmt keine Dateien über 25 MB an? Teilen Sie sie nach Größe, nach Seitenbereichen oder alle paar Seiten. Sie können sie auch komprimieren, damit sie weniger wiegen.

Mit der Kamera scannen

Halten Sie das Blatt vor die Laptop-Kamera: Das Programm erkennt es (markiert es grün), schneidet es zu und begradigt es. Ein Foto pro Seite, und es erstellt die PDF für Sie.

Mit Kennwort schützen

Schützen Sie eine PDF vor dem Versenden mit AES-256-Verschlüsselung, oder entfernen Sie das Kennwort einer PDF, das Sie bereits kennen.

Alles schnell finden

Geben Sie ins Suchfeld ein, was Sie brauchen („zusammenführen“, „Kennwort“, „Foto“), und das Werkzeug erscheint. Es hat einen dunklen Modus und folgt dem Windows-Design.

Ozone PDF

Wirklich offline

  • Es hat nichts, womit es sich verbinden könnte. Das Programm wird ohne die Teile von Python gebaut, die das Netzwerk nutzen, und jede Version wird darauf geprüft.
  • Und sicherheitshalber die Firewall. Das Installationsprogramm fügt eine Regel in der Windows-Firewall hinzu, die jede Verbindung blockiert.
  • Sie können es überprüfen. Der Code ist offen: Jeder kann sehen, was jeder Teil macht.
  • Es entfernt, was man nicht sieht. Die erstellten PDFs enthalten weder Autor noch Anhänge oder versteckte Daten des Originals.

Unser Versprechen

Sicherheit ist nicht einfach eine weitere Funktion: Sie ist der Grund, warum es Pache Labs gibt. Jede Version wird darauf geprüft, dass das Programm keine Verbindung zum Internet herstellt, der Code bleibt offen, damit ihn jeder prüfen kann, und wir werden niemals Werbung, Konten oder Tracking hinzufügen. Sollte eine Änderung jemals Ihre Daten gefährden, wird sie nicht veröffentlicht.

Ozone PDF herunterladen

Kostenlos, für Windows 10 und 11 (64 Bit).

Conseguilo en Microsoft Store Installationsprogramm herunterladen (.exe)

Empfohlen: Aus dem Microsoft Store wird es ohne Windows-Warnungen installiert und aktualisiert sich selbst.

Sind Sie eine Organisation? Verwenden Sie das .msi-Installationsprogramm, um es mit GPO, Intune oder SCCM auf allen PCs zu installieren.
.msi-Installationsprogramm herunterladen So wird es installiert

Quellcode der Version 1.2.0

Zeigt Windows beim Installieren eine Warnung?

Beim .exe-Installationsprogramm kann Windows „Der Computer wurde durch Windows geschützt“ anzeigen, weil das Programm neu ist und noch nicht viele Leute es heruntergeladen haben. Klicken Sie auf Weitere Informationen und dann auf Trotzdem ausführen. Wenn Sie es aus dem Microsoft Store installieren, erscheint diese Warnung nicht.

Installation in einer Organisation

Wenn Sie in der IT arbeiten und es auf allen PCs installieren möchten, gibt es dafür ein .msi-Installationsprogramm. Es funktioniert mit Gruppenrichtlinien (GPO), Intune oder SCCM.

  • Es wird für alle Benutzer des Computers installiert, in C:\Program Files\Ozone PDF.
  • Es erstellt dieselbe Firewall-Regel, die dem Programm den Internetzugang sperrt, und entfernt sie bei der Deinstallation.
  • Jede neue Version ersetzt die vorherige automatisch.
  • Keine Telemetrie, keine Lizenzen pro Gerät und keine Server zu warten.
Die .msi herunterladen

Installation ohne Fenster

msiexec /i Ozone_PDF.msi /qn

Deinstallation

msiexec /x Ozone_PDF.msi /qn

Firewall-Regel prüfen:

Get-NetFirewallRule -DisplayName "Ozone PDF - sin red"

Ozone PDF

处理 PDF，无需上传到互联网。

免费签名、编辑、遮盖信息、合并、拆分、压缩和扫描文档。一切都在你的电脑上完成。

免费下载 了解使用方法

适用于 Windows、Mac 和 Linux。免费且开源。

我为什么做它

我做这个程序，是因为看到很多在各行各业处理敏感信息的人，用网站来合并或压缩 PDF：合同、工资单和身份证最后都被上传到不知道是谁在运营的网站。如今网络攻击越来越频繁，人工智能又让攻击变得更容易，上传到互联网的文件就是暴露的文件。Ozone PDF 能做那些网站做的事，但一切都在您的电脑上完成。

不用打印就能签名和批注

只需画一次签名（可在下方加上姓名、职位或执业编号），放到需要的地方。高亮、下划线、写字、画框或手绘：都可以移动和修改。出错了，按 Ctrl+Z 即可撤销。

真正遮盖你的信息

标出身份证号、银行账号或任何不想公开的内容：保存时，下面的内容会从文件中删除，而不只是盖上黑框。

把多个 PDF 合并成一个

把文件拖进窗口，按您想要的顺序排列，就完成了：得到一个 PDF。原文件保持不变，总是另存一份新副本。

Word 转 PDF，PDF 转 Word

把 Word 文档转成 PDF 方便发送，或把 PDF 转成 Word 方便编辑。标题、粗体、列表、表格和图片都会保留，无需把文件上传到任何网站。

拆分文件，方便通过邮件发送

系统不接受超过 25 MB 的文件？可以按大小、页面范围或每隔几页拆分。也可以压缩，让文件变小。

用相机扫描

用相机拍下纸张，或从照片中选择：程序会识别、裁剪、摆正，并处理成扫描件的效果。每页一张照片，就能生成 PDF。

加上密码

发送前用 AES-256 加密保护 PDF，或者移除您已知密码的 PDF 的密码。

快速找到所有功能

在搜索框里输入需要的功能（“合并”“密码”“照片”），对应的工具就会出现。有浅色和深色模式，随你选择。

Ozone PDF

真正的离线

  • 它根本无法联网。 程序内部的安全规则禁止它连接任何服务器，每个版本都会测试确认。
  • 以防万一，还有防火墙。在 Windows 上，安装程序会添加一条防火墙规则，阻止它进行任何连接。
  • 您可以亲自检查。代码是开源的：任何人都能看到每个部分做了什么。
  • 它会先提醒你。 如果要保存到会同步到云端的文件夹（OneDrive、Google Drive、Dropbox），或 PDF 带有数字签名，它会告诉你。
  • 清除看不见的信息。 一键删除 PDF 的作者、附件和隐藏数据，再分享出去。

我们的承诺

安全不只是一个功能：它是 Pache Labs 存在的原因。每个版本都会测试，确认程序不会连接互联网；代码保持开源，任何人都能审查；我们永远不会加入广告、账号或跟踪。如果某次修改会让您的数据面临风险，它就不会发布。

安装时 Windows 显示警告？

使用 .exe 安装程序时，Windows 可能会显示“Windows 已保护你的电脑”，因为这个程序很新，下载的人还不多。请点击更多信息，然后点击仍要运行。如果从 Microsoft Store 安装，就不会出现这个警告。

Mac 不让你打开？

打开 .dmg，把 Ozone PDF 拖到“应用程序”。第一次打开时，Mac 可能会提示无法验证该程序，因为它还没有经过 Apple 签名。前往系统设置 > 隐私与安全性，点按仍要打开。只需要操作一次。

在机构中安装

如果您是 IT 人员，想把它安装到所有电脑上，可以使用专门的 .msi 安装程序。它支持组策略（GPO）、Intune 或 SCCM。

  • 为电脑上的所有用户安装，位置为 C:\Program Files\Ozone PDF。
  • 程序本身已内置联网阻止。如果你还想要 .exe 安装程序创建的那条防火墙规则，可以用旁边的命令添加。
  • 每个新版本都会自动替换旧版本。
  • 没有遥测，没有按设备授权，也没有需要维护的服务器。

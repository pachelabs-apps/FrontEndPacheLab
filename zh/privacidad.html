隐私

最后更新：2026 年 11 月 5 日

Pache Labs 的理念很简单：您的文件属于您。以下是这些程序会做和不会做的事，先从 Ozone PDF 说起。

Ozone PDF 不收集数据

  • 不连接互联网。不会把您的文档、照片或任何其他数据发送到任何服务器，无论是我的还是别人的。
  • 没有广告、账号或使用统计。我不知道谁在用它，也不知道用来做什么。
  • 一切都在您的电脑上处理。生成的文件保存在您选择的位置。如果该文件夹与云服务（如 OneDrive 或 Google Drive）同步，该服务会按照它自己的政策上传这些文件。

它在您电脑上保存的内容

  • 偏好设置：主题（浅色或深色）、语言、菜单是否折叠，以及“完成后打开”和“清空列表”复选框。它们保存在您用户的 Windows 注册表中。
  • 相机照片：使用“照片转 PDF”时，照片会在您工作期间保存在您用户的临时文件夹中，关闭程序时会被删除。

相机

Ozone PDF 只有在您打开“照片转 PDF”时才使用相机，而且只在该窗口打开期间使用。图像不会离开您的电脑。您可以在 Windows 设置 > 隐私和安全性 > 相机 中允许或阻止访问。

本网站

本网站不使用 Cookie、跟踪或广告工具，字体也从本站加载。托管本站的服务可能出于安全原因，按照其自身政策记录访问的技术数据（如 IP 地址）。如果您捐款，您选择的平台（Cafecito 或 GitHub Sponsors）会处理您的支付数据；我只能看到该平台向我显示的内容。

建议表单

如果您通过本网站给我发送建议，消息（以及您填写的名字和邮箱）会通过表单发送服务 Web3Forms 以邮件形式发给我。我只用它来阅读和回复您；不会分享，也不会用于广告。如果您希望我删除您的某条消息，请发邮件告诉我。

联系方式

如对本政策有疑问，请写信至 pache.labs@gmail.com。
